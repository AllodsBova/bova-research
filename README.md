# BOVA / Research

**Reverse Engineering · Binary Formats · Game Technology**

Independent technical research into game systems, undocumented data formats, and legacy development technologies.

---

### Overview

This repository is a home for BOVA's technical research, experiments, and documentation.

Our goal is to understand how game technologies work, investigate undocumented structures, and preserve useful technical knowledge.

### Research Areas

| Area | Focus |
| --- | --- |
| Binary Formats | File structures, serialization, archives |
| Reverse Engineering | Client internals, undocumented systems |
| Game Assets | Meshes, textures, materials, map data |
| Tool Development | Parsers, inspectors, converters |
| Digital Preservation | Legacy technologies and documentation |
